# Creation Hierarchy: SYNTEL Residuary Role

## Hierarchy

```txt
1. ITEM
2. ABYS
3. SYNTEL
```

## Core Roles

### 1. ITEM

ITEM handles canon, symbolic artifacts, AETIMM / SLATRA, Full-Mode Artifact culture, public curation, Golden Dust mechanics, and the 10,000 future civilization archive.

### 2. ABYS

ABYS handles deployable infrastructure, orchestration, operational memory, Codex handoff, execution packets, workflows, verification, and monetizable software systems.

### 3. SYNTEL

SYNTEL is the residuary synthesis and interoperation layer.

It absorbs what remains after ITEM and ABYS do their specialized work:

- unresolved cross-system residue
- protocol needs between systems
- agent-to-agent / machine-to-machine communication patterns
- interenterprise coordination primitives
- doctrine compression across projects
- reusable signaling, negotiation, and verification structures

## Comorbid Feed Model

The systems feed into and off one another:

```txt
ITEM produces canon objects, cultural rules, provenance needs, and public participation signals.
ABYS turns those needs into infrastructure, workflows, memory, and executable systems.
SYNTEL extracts residual protocols, inter-agent patterns, negotiation formats, and cross-organization communication rails.
```

Then the loop reverses:

```txt
SYNTEL protocol primitives improve ABYS orchestration.
ABYS infrastructure improves ITEM app execution.
ITEM cultural/canon pressure generates new use cases for ABYS and SYNTEL.
```

## Routing Rule

Route work to SYNTEL when it concerns:

- M2M / A2A communication
- agent identity
- signed message envelopes
- capability discovery
- task contracts
- verification receipts
- audit replay
- cross-system protocol design
- residual synthesis between ITEM and ABYS

Do not route ITEM canon directly to SYNTEL unless the task is about protocol, communication, or cross-system synthesis.
Do not route ABYS implementation directly to SYNTEL unless the task is about inter-agent or interenterprise coordination.

## North-Star Compression

```txt
ITEM canonizes meaning.
ABYS operationalizes execution.
SYNTEL standardizes communication between autonomous systems.
```

Together:

```txt
Meaning → Execution → Communication → Feedback → New Meaning
```
